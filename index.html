Athena+

CSCI 4800: Human Computer Interaction - Athena+ Prototype

    The goal of the project was to make a more user friendly experience for the class registration software used by The University of Georgia: Athena. Applying prototyping techniques such as wireframing, my team and I used the prototyping software Figma to make a mock application called Athena+. Our main goals were to reduce the short term memory overload that users experienced when trying to use Athena. Normally, Athena puts all information such as class view, plan creation, major requirement, etc. all on a single page. Our goal was to split this up into more managable subsections that made it so users could easily accomplish their current task for class registration. By splitting Athena into 3 different sections (Class View, Plan Compare, and Help) the Athena+ prototype alleviated short term memory overload for users and increased user satisfaction when registering for classes compared to the in use Athena site.
